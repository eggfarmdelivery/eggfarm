# 에그팜 (EGG FARM)

계란 B2C(일반배송/정기배송) + B2B(건바이건 발주) 통합 배송 플랫폼.
오더모아(groupbuy) 코드베이스의 배송위임/사진워터마크/카카오알림 모듈을 재사용.

## 기술 스택
- Next.js + Tailwind CSS + Supabase(DB/Auth)
- 로그인: 카카오 로그인만 사용(B2C/B2B 모두), 이메일가입 없음
- 관리자 콘솔: 별도 비밀번호 로그인(카카오 불필요)

## 확정된 핵심 정책
- **B2C**: 일반배송(건바이건 입금확인) / 정기배송(크레딧 구매·차감) 두 갈래
- **B2B**: 건바이건 발주, 선배송후정산(배송완료 사진 → 카톡 입금요청 → 입금확인 → 카톡 확인알림)
  - 평일 매일 공통 마감시각(1개 값), 거래처별 계약단가 별도 관리
- **재고/인당한도**: B2C+B2B 공통 적용. 상품별 기준재고+초과허용비율(기본 30%)+1인당한도를
  `product_limit_schedule`에 적용일자와 함께 예약 등록 → 조회시점에 최신값 자동반영(배치작업 불필요)
  - 기준 이하: 자동 진행 / 기준~기준*(1+초과허용비율): "초과승인대기" 상태로 관리자 승인 필요 / 초과: 자동 마감
- **배송가능 단지**: B2C 전용, 관리자가 등록/활성관리, 회원가입 시 탭으로 선택(자유주소 아님)
- **정산**: B2B 월 정산은 익월초 마감→계좌이체 즉시 완료(미수금 없음), 이체완료 시 거래처 담당자에게
  카톡(요약+상세페이지 링크, `b2b_settlement.detail_token`) 발송
- **견적문의**: 비회원 대상, 자동계산 없이 문의만 접수 → 관리자가 직접 회신
- **컬러**: A1(진한 앰버, #E8940C) 확정. 로고 파일 각 페이지 상단 배치 예정
- **알림**: 카카오 "나에게 보내기" 방식 — 각 계정(B2C/B2B)이 카카오 로그인 시 메시지전송 동의를
  함께 받아 토큰 저장, 이후 해당 계정 본인에게만 알림 발송(오더모아에서 실사용 검증된 방식)

## 백로그 (이번 범위 제외, 나중에 적용)
- 매장 QR / 제휴업체 프로모션 QR — 전체 보류
- 배달원(알바) 리크루팅: 지도기반 단지 선택 지원 → 승인(단지당 1명) → 건당수수료
  80% 즉시지급 / 20% 유보 → 퇴사시 일괄정산. 사업소득(3.3%) 처리, 위탁계약 형태 권장.
  스키마는 미리 만들어둠(courier, courier_zone, courier_settlement, courier_deposit_ledger)

## 폴더 구조
```
app/
  b2c/      # 홈, 배송방식선택, 일반배송주문, 정기배송, 배송현황, 마이페이지
  b2b/      # 로그인, 발주, 배송현황
  admin/    # 콘솔, 재고/한도설정, B2B정산, 견적문의함
  quote/    # 비회원 견적문의
lib/
  supabase.ts
  kakao.ts
supabase/migrations/0001_init.sql   # 전체 DB 스키마
```
